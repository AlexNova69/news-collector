# Инструкция по сборке самодостаточного EXE

## Требования
- Windows 7/8/10/11
- Python 3.7+ (только для сборки, не для запуска)
- Интернет для скачивания зависимостей

## Шаги сборки

1. **Установите Python** (если не установлен):
   - Скачайте с python.org
   - Отметьте "Add Python to PATH"

2. **Скачайте файлы проекта**:
   - `news_collector.py`
   - `build_exe.py`
   - `requirements.txt`

3. **Запустите сборку**:
   ```cmd
   python build_exe.py
