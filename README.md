# 📰 News Collector — сборщик новостей для бегущей строки

Самодостаточное Windows-приложение: периодически собирает новости с настроенных
сайтов, чистит их от мусора, сжимает до одной строки и записывает текстовый файл
для системы бегущей строки (UTF-16 LE с BOM). Работает в трёх режимах:
интерактивное меню, разовый сбор из командной строки и **служба Windows**
с автозапуском после перезагрузки.

Внешние API и ключи не нужны — только сами сайты-источники.

## Состав

| Файл | Назначение |
|---|---|
| `news_collector.exe` | всё приложение (меню + сбор + служба), Python не требуется |
| `sources.json` | источники новостей и настройки (папка/имя файла, интервал службы) |
| `filters.json` | фильтры очистки текста (стоп-слова, шаблоны начала/конца) |
| `news_call.txt` | выходной файл для бегущей строки (создаётся программой) |
| `news_collector.log` | журнал службы/разового сбора (создаётся программой) |
| `install_service.bat` | установка службы Windows с автозапуском (от администратора) |
| `uninstall_service.bat` | остановка и удаление службы (от администратора) |

## Быстрый старт

1. Скачайте `news_collector.exe` со страницы [Releases](https://github.com/AlexNova69/news-collector/releases)
   и положите в отдельную папку (например, `D:\NewsCollector`).
2. Запустите exe двойным кликом — откроется меню. При первом запуске можно
   согласиться на быстрый старт: добавятся примеры источников (47news.ru,
   Фонтанка и др.).
3. Отредактируйте источники под себя (пункты 2–4 меню) и настройте папку и имя
   файла автосохранения (пункт 11).
4. Проверьте сбор: пункт 6 — новости сразу собираются и сохраняются в
   настроенный файл.
5. Для работы без участия человека установите службу (см. ниже) — сбор будет
   идти сам, в том числе после перезагрузки компьютера.

## Главное меню

```
1.  Показать источники            — список с URL и лимитом новостей
2.  Добавить источник             — название, URL, макс. число новостей
3.  Редактировать источник
4.  Удалить источник
5.  Управление фильтрами          — стоп-слова и шаблоны без знания regex
6.  Собрать и экспортировать      — сбор сразу в папку/файл из пункта 11
7.  Настроить автоматический сбор — интервал внутри приложения (30 мин … 5 ч, ежедневно)
8.  Запустить фоновый планировщик — работает, пока открыто окно программы
9.  Остановить планировщик
10. Быстрый старт                 — добавить примеры источников
11. Настроить папку автосохранения и имя файла
12. Системная информация          — версия, настройки, наличие файлов, фильтры
0.  Выход
```

Пункт 6 не задаёт вопросов: папка и имя файла берутся из настроек пункта 11.
Это же место используют служба и `--once`.

## Настройки — sources.json

```json
{
  "sources": {
    "online47.ru": { "url": "https://online47.ru", "max_news": 5 }
  },
  "settings": {
    "auto_save_directory": "D:/Beguchka/Text",
    "auto_save_filename": "news_call.txt",
    "service_interval_min": 30,
    "log_file": true,
    "log_days": 3
  }
}
```

| Ключ | Смысл | По умолчанию |
|---|---|---|
| `sources.<имя>.url` | адрес сайта-источника | — |
| `sources.<имя>.max_news` | сколько новостей брать с источника за сбор | 5 |
| `settings.auto_save_directory` | папка выходного файла; `null` = папка рядом с exe | папка программы |
| `settings.auto_save_filename` | имя выходного файла | `news_call.txt` |
| `settings.service_interval_min` | период службы, минут (5…1440) | 30 |
| `settings.log_file` | писать ли журнал `news_collector.log` (`true`/`false` или `"on"`/`"off"`) | `true` |
| `settings.log_days` | хранить журнал N дней, старшее удаляется (0 — вечно) | 3 |

Папку и имя файла удобнее менять пунктом 11 меню, интервал — командой
`news_collector.exe --interval 15` (сохраняется в этот же файл).

## Формат выходного файла

UTF-16 LE с BOM — родной формат систем бегущей строки. Новости сгруппированы
по источникам: строка-название источника, затем по одной новости на строке,
между источниками пустая строка:

```
online47.ru
Белорусский опыт и цифровизация: как на пресс-клубе губернатора Ленобласти обсуждали подготовку региона к зиме
Александр Дрозденко рассказал о готовности Ленинградской области к отопительному сезону
Где привиться от гриппа в Ленобласти: адреса, сроки и рекомендации врачей

n-put.ru
…
```

Каждая новость — одна строка, сжатая до 200 символов. Файл записывается
**атомарно** (сначала во временный файл, потом мгновенная замена): бегущая
строка никогда не видит недописанный файл.

## Обработка новостей

1. **Сбор** — страницы источников разбираются, заголовки новостей забираются
   с учётом лимита `max_news`.
2. **Фильтры** (см. ниже) — удаление стоп-слов, символов, мусора в начале и
   конце строки.
3. **Сжатие** — встроенный упрощённый пересказ доводит строку до 200 символов
   (внешние AI-сервисы не используются).
4. **Дедупликация** — повторяющиеся новости отбрасываются (по заголовку и
   схожести текста, включая повторы между источниками).

## Фильтры — filters.json

Настраиваются вручную в файле или пунктом 5 меню (без знания regex — достаточно
ввести обычный текст, система сама построит шаблон и обобщит числа/даты).

```json
{
  "global_filters": {
    "stop_words":     ["читать дальше", "подробнее", "реклама"],
    "stop_symbols":   ["➡", "🔥"],
    "regex_patterns": ["^\\d{1,2}:\\d{2}\\s*$"],
    "start_patterns": ["Сегодня,?\\s*\\d{1,2}:\\d{2}"],
    "end_patterns":   []
  },
  "source_specific_filters": {
    "47news.ru": { "stop_words": ["Афиша"] }
  }
}
```

- `stop_words` — удалить фразу в любом месте строки;
- `stop_symbols` — удалить эмодзи/символы;
- `regex_patterns` — удалить строки целиком, подходящие под шаблон;
- `start_patterns` — срезать префикс (время, даты вида «Вчера, 16:16»);
  после среза подчищается оголившееся время;
- `end_patterns` — срезать суффикс;
- фильтры источника применяются в дополнение к глобальным.

После правки `filters.json` перезапускать программу не нужно — файл
перечитывается при каждом сборе.

## Служба Windows (автозапуск после перезагрузки)

Установка — **от администратора** (правый клик по `install_service.bat` →
«Запуск от имени администратора»), либо командами:

```
news_collector.exe install --startup auto   # установить с автозапуском
news_collector.exe start                    # запустить
news_collector.exe stop                     # остановить
news_collector.exe restart                  # перезапустить
news_collector.exe remove                   # удалить службу
news_collector.exe debug                    # работа службы в консоли (Ctrl+C — выход)
```

Служба каждые `service_interval_min` минут собирает новости и записывает
выходной файл по настройкам автосохранения. Изменить период:

```
news_collector.exe --interval 15    # минут; сохраняется в sources.json
```

Удаление службы — `uninstall_service.bat` (тоже от администратора).

## Журнал — news_collector.log

У службы нет консоли, поэтому всё важное пишется в `news_collector.log` рядом
с exe (тот же журнал ведёт и `--once`):

```
15.10.2026 22:42:33  NewsCollector 1.3.0 | источников: 6 | период: 30 мин | файл: D:/Beguchka/Text/news_call.txt
15.10.2026 22:43:01  обновлено: 30 новостей -> D:/Beguchka/Text/news_call.txt
15.10.2026 22:43:01  следующее обновление через 30 мин…
```

Записи старше `log_days` дней удаляются раз в сутки; при росте файла больше
1 МБ он переносится в `news_collector.log.old`. Отключить журнал:
`"log_file": false` в `sources.json`. Ошибки службы дублируются в журнал
событий Windows (Просмотр событий → Приложение).

## Командная строка

```
news_collector.exe                 # меню (двойной клик — то же самое)
news_collector.exe --once          # один сбор и экспорт, без меню
news_collector.exe --interval 15   # установить период службы (минуты)
news_collector.exe --help          # справка
```

`--once` удобен для проверки настроек, запуска из Планировщика заданий Windows
или батника.

## Сборка exe из исходников

Требуется Python 3.8+ (только для сборки):

```
python -m pip install pyinstaller pywin32 requests beautifulsoup4 schedule lxml
python build_exe.py
```

Готовый exe появится в `dist\` и в `NewsCollectorDist\`. Для работы службы в
сборку обязательно нужен пакет `pywin32` (без него exe сообщит, что сервисный
режим недоступен).

## Запуск из исходников без сборки

```
python -m pip install requests beautifulsoup4 schedule lxml pywin32
python news_collector.py            # меню
python news_collector.py --once     # разовый сбор
```

Веб-интерфейс (опционально): см. [README_WEB.md](README_WEB.md).

## Решение проблем

| Симптом | Причина и решение |
|---|---|
| «Требуются права администратора» при установке службы | так и должно быть: правый клик по `install_service.bat` → «Запуск от имени администратора» |
| Служба установлена, но файл не появляется | смотрите `news_collector.log` рядом с exe; проверьте, что папка из пункта 11 существует и доступна |
| В файле/консоли «кракозябры» | выходной файл — UTF-16 LE с BOM; открывайте редактором с автоопределением кодировки (Блокнот Windows понимает) |
| Новости не собираются с сайта | сайт недоступен или сменил разметку; уменьшите `max_news`, проверьте URL в браузере |
| Одинаковые новости повторяются | добавьте фильтр или стоп-слово (пункт 5 меню), дедупликация работает по заголовку |
| «Сервисный режим недоступен: нет модулей pywin32» | exe собран без pywin32 — пересоберите с установленным `pywin32` |
