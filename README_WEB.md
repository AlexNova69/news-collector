# Web UI для News Collector

Простой веб-интерфейс для системы сбора новостей (на Flask). Позволяет
управлять источниками, фильтрами и запускать сбор из браузера — удобно,
когда News Collector работает на машине, куда не хочется заходить по RDP
ради консольного меню.

> Основной способ работы — `news_collector.exe` (меню или служба Windows,
> см. [README.md](README.md)). Веб-интерфейс — необязательное дополнение.

## 🚀 Быстрый запуск

### Вариант 1: Прямой запуск
```bash
python -m pip install flask requests beautifulsoup4 schedule lxml
python web_ui.py
```

### Вариант 2: Через скрипт запуска (проверит зависимости)
```bash
python run_web.py
```

После запуска интерфейс доступен по адресу: **http://localhost:5000**

## 📋 Возможности

- просмотр, добавление, редактирование и удаление источников;
- управление фильтрами (стоп-слова, шаблоны начала/конца);
- запуск сбора новостей кнопкой из браузера;
- просмотр текущих настроек и результатов.

## ⚙️ Настройки

Интерфейс использует те же файлы, что и консольное приложение:
`sources.json`, `filters.json`. Выходной файл (`news_call.txt`, UTF-16 LE)
создаётся по настройкам автосохранения — как в пункте 11 меню.

## Замечания

- Открывать нужно только на своей машине (`localhost`); для доступа с других
  компьютеров меняйте `host`/`port` в `web_ui.py` на свой страх и риск —
  авторизации в интерфейсе нет.
- Для автозапуска после перезагрузки используйте службу Windows из
  основного README, а не веб-интерфейс.
